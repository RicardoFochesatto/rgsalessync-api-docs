## Ajustes desta versão

- Navegação lateral sem o efeito de "pisca" durante o scroll suave.
- A seleção do menu fica travada na seção escolhida durante a navegação e volta ao controle automático após a rolagem.
- Tipografia maior e melhor aproveitamento da área central.
- Tabelas, exemplos e blocos de código com leitura mais confortável.
- Todos os mocks possuem cenários de sucesso e de erro selecionáveis.
- Os mocks continuam sendo locais: nenhuma requisição real é enviada ao ERP.
